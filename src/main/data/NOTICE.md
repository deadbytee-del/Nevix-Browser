# Bundled filter data

- `pgl-hosts.txt` — Peter Lowe's Ad and tracking server list (https://pgl.yoyo.org/adservers/), snapshot of 2026-09-30. Free to use and redistribute; credit to Peter Lowe.
- `core-rules.txt` — hand-curated Nevix rules (MIT, same as the project).

Optional lists (EasyList, EasyPrivacy, StevenBlack, uBlock filters) are **not** bundled; they are downloaded from their publishers only if the user enables them, under their own licenses.
